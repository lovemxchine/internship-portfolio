## ข้อเท็จจริงที่ตรวจแล้ว (ไม่ต้องตรวจซ้ำ)

- Canva Website = **หลายหน้าจริง** แต่ละหน้าตั้ง URL path เองได้ (`/week-03`) มีเมนูอัตโนมัติ ซ่อนรายหน้าได้
- ได้ของแถม: ตั้งรหัสผ่านทั้งเว็บได้ + ปิดไม่ให้ Google เจอได้
- **เนื้อหาจริงในระบบตอนนี้แทบไม่มี** — ของจริงมีแค่ ชื่อ / รหัสนักศึกษา / บริษัท / แผนก / ช่วงเวลา
  ที่เหลือ (intro, education, skills, talents, contacts, summary ทั้งใบ, 4 สัปดาห์, 12 แกลเลอรี) เป็น placeholder ล้วน
  → สิ่งที่ต้องส่งมอบคือ **โครงให้กรอก** ไม่ใช่ข้อความพร้อม copy

## โครงหน้าที่ต้องทำใน Canva

4 หน้าหลัก (ขึ้นเมนู): หน้าแรก · ประวัติส่วนตัว · แกลเลอรี · สรุปผลฝึกงาน
\+ แม่แบบหน้าสัปดาห์ 1 ใบ ให้ duplicate: เลขสัปดาห์ · ช่วงวันที่ · หัวข้อ · งานที่ได้รับมอบหมาย · ขั้นตอนการทำงาน (list) · สิ่งที่ได้เรียนรู้ · ปัญหา · วิธีแก้ · รูป
แกลเลอรีมี 4 หมวด: การทำงาน · การประชุม · กิจกรรมบริษัท · ผลงานที่ภาคภูมิใจ
