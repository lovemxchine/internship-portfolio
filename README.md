# เว็บไซต์บันทึกผลงานฝึกงาน

หน้าบ้านของระบบบันทึกผลงานการฝึกงานรายสัปดาห์ — Astro + GitHub Pages

## คำสั่ง

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | เปิดเซิร์ฟเวอร์สำหรับพัฒนา |
| `npm run build` | สร้างไฟล์เว็บลง `dist/` |
| `npm run preview` | ดูผลของไฟล์ที่ build แล้ว |

## แก้ไขเนื้อหา

เนื้อหาทุกชิ้นอยู่ใน `src/content/` เท่านั้น หน้าเว็บไม่มีข้อความฝังไว้

```
src/content/
├── profile.json     ประวัติส่วนตัว (มีชุดเดียว)
├── summary.json     สรุปผลการฝึกงาน (มีชุดเดียว)
├── gallery.json     แกลเลอรี
└── weeks/           หนึ่งไฟล์ = หนึ่งสัปดาห์
```

เพิ่มสัปดาห์ใหม่ = คัดลอกไฟล์ `weeks/week-04.md` แล้วแก้ค่าข้างใน
รูปวางไว้ใน `src/assets/` ระบบย่อขนาดและแปลงเป็น WebP ให้เองตอน build

ศัพท์ของโดเมนดูที่ [CONTEXT.md](./CONTEXT.md)

## ย้ายไปบัญชีอื่น

แก้ `SITE` และ `BASE` ใน `astro.config.mjs` ให้ตรงกับบัญชีและชื่อ repo ใหม่

## สถานะ

เฟสปัจจุบันคือหน้าบ้านสำหรับ demo — ยังไม่มีระบบหลังบ้าน
เนื้อหาและรูปทั้งหมดเป็นข้อมูลตัวอย่าง
